# Game Lab — Worlds in Progress

## Purpose

`6th_GameLab` is a projector-first teaching app for a sixth-grade STEM unit that moves from game design to Scratch storytelling and finally to clay stop-motion. It is built to restore play, curiosity, and visible student agency while keeping every class period academically explicit.

## Experience

Students travel through seven connected “worlds.” Each class day is a complete lesson with a bell ringer, mission, vocabulary, teacher model, playable example, guided practice, independent work, CFU, and exit ticket. The on-screen example makes the lesson’s purpose visible before students are asked to create.

The visual language is an arcade cabinet crossed with a designer’s sketchbook: saturated color, hand-drawn marks, chunky controls, and a guide character named Pixel. The tone is energetic without talking down to students.

## Teaching flow

Every lesson follows the same predictable sequence:

1. Bell Ringer
2. Mission + Purpose
3. Vocabulary
4. I Do
5. Play the Example
6. We Do
7. You Do
8. CFU
9. Exit Ticket

Teacher notes and materials stay available in a separate drawer so the projected student view remains clean.

## Unit arc

- Nov. 9–13: Inventor’s Arcade — goals, rules, sequence, feedback, fairness, paper prototypes
- Nov. 16–20: Code Caverns — sprites, coordinates, events, loops, conditionals, variables
- Nov. 23–24: Bug Bazaar — debugging, playtesting, accessibility
- Nov. 30–Dec. 4: Story Forge — worlds, storyboards, characters, camera shots, timing
- Dec. 7–11: Scratch Studio — scenes, dialogue, transitions, sound, captions, peer feedback
- Dec. 14–18: Claymotion Workshop — models, sets, lighting, frames, production roles
- Dec. 21–23: Premiere Portal — filming, editing, accessibility, showcase, reflection

## Accessibility

- Keyboard and pointer operation
- Large-text, high-contrast, reduced-motion, and sound controls
- Visible instructions and status messages
- No color-only directions
- Captions/transcripts for sound-based examples
- Pause/reset controls
- Plain-language “Watch / Try / Explain” structure
- Notebook or physical alternative for every digital build

## Technical approach

The project is a dependency-free static site for GitHub Pages. Lesson content is data-driven; the same presentation and game engines serve all 30 days. The site stores display preferences locally, but requires no account or student data.
