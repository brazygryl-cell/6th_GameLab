# 6th Game Lab: Worlds in Progress

An interactive, projector-first 6th-grade STEM unit for Ms. CJ. Thirty daily lessons move from game design to Scratch storytelling to clay stop-motion.

## What is included

- 30 complete daily lessons from Nov. 9 through Dec. 23
- A playable example for every day
- Presentation mode, timers, keyboard shortcuts, and teacher notes
- Built-in large text, high contrast, reduced motion, captions, and sound controls
- Notebook/low-tech alternatives for limited Chromebook access

## Run locally

Open `index.html` directly, or serve the folder with any simple static server.

## GitHub Pages

Publish the root of the `main` branch.

## Teacher shortcuts

- `←` / `→`: previous or next lesson section
- `T`: open teacher drawer
- `A`: open accessibility controls
- `F`: presentation mode
- `R`: reset the current example game
- `Esc`: close an open panel

See `docs/DESIGN.md` for the complete design rationale.
